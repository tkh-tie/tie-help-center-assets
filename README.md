# Tie Help Center assets

Images referenced by Help Center articles. Intercom fetches each image on publish and re-hosts it, so this repo only has to be reachable at push time, but it stays as the versioned master.

Layout mirrors the article source: `<section>/assets/<article-slug>--<nn>-<what>.png`. Each folder has a `README.md` line per image: capture date, what it shows, which article uses it.
